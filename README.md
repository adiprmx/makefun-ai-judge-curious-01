A program that writes one short text to make the AI judge feel curious — a calm, concrete morning scene with one unanswered question: a baker who sets out an extra loaf every day for a customer who never comes, and by noon it is always gone.

Run it with Node 22:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes the text to `out/entry.txt` (deterministic: the same text on every run, stdlib only, no network).
